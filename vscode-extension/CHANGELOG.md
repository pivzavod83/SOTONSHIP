# Changelog

## 0.1.0

- Add a VS Code workbench for the existing local COBOL-to-Java verification API.
- Verify selected editor documents with explicit field mapping, finite input bounds and reference-rate identity.
- Include the penny drift fixture, counterexample inspection and proposed-fix verification.
- Compare Java with a proposed fix in the native diff editor.
- Reverify and check current source hashes before applying a fix as an undoable, unsaved editor edit.
- Include a JSON schema for the 12-field proof-input contract.
